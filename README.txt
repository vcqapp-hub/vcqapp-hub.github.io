PUBLISHING
1. Under the GitHub account/organization vcqapp-hub, create a repository named exactly vcqapp-hub.github.io.
2. Upload every file from this package to the repository root. Keep the assets folder unchanged.
3. In Settings > Pages, publish from main / root if Pages is not already active.
4. Confirm these URLs load:
   https://vcqapp-hub.github.io/
   https://vcqapp-hub.github.io/robots.txt
   https://vcqapp-hub.github.io/sitemap.xml
   https://vcqapp-hub.github.io/llms.txt
   https://vcqapp-hub.github.io/llms-full.txt
   https://vcqapp-hub.github.io/ai.txt
5. Add https://vcqapp-hub.github.io/ to Google Search Console.
6. Submit https://vcqapp-hub.github.io/sitemap.xml.
7. Use URL Inspection to request indexing for the homepage.
8. Add links back to the VCQ hub from each app website footer to strengthen publisher/app relationships.

DISCOVERABILITY INCLUDED
- Semantic visible app descriptions
- Canonical portfolio URL
- Organization, WebSite, CollectionPage and ItemList structured data
- Product identity, package IDs and canonical app links
- OpenGraph and Twitter Card
- robots.txt and portfolio sitemap
- llms.txt, llms-full.txt, ai.txt and humans.txt
- Minimal-JavaScript, crawlable static page
- Accessible alt text and reduced-motion support

NOTES
Search rankings and inclusion in AI-generated answers cannot be guaranteed. The package improves crawlability, structured entity identity, internal linking and public source consistency.
